## 相比上游多了什么

| 功能 | 说明 |
|---|---|
| **Web 控制台** | 浏览器点点就能刷课，不用记命令行参数；配置、选课、进度、日志一站式 |
| **实例控制台** | 网关上每个账号一张卡：独立开关启停、右下角加号随时增账号、一键全停 |
| **多账号并行** | 一份代码 + 多个独立数据目录，各账号的 cookies / 题库缓存 / 学习库完全隔离 |
| **统一网关** | 一个入口管理所有账号实例，内置反向代理，无需逐端口访问 |
| **远程访问** | 配合内网穿透（只需 **1 条隧道**），手机在外网也能看进度 |
| **三级访问权限** | 管理员 / 学习通账号本人 / 只读访客，权限在网关层卡死 |
| **错峰调度** | 按设定间隔依次启动各账号，避免请求密度叠加触发平台进度回溯 |
| **日志清洗** | 过滤终端控制符，网页日志区不再被刷屏（可读性修复） |
| **数据自动续刷** | 进程被重启后自动接回上次进度，无需人工干预 |

## 快速开始

### 1. 环境要求

- Python 3.13+
- Windows / Linux / macOS 均可（多实例启动器目前针对 Windows 优化）

### 2. 安装

```bash
git clone https://github.com/<你的用户名>/<仓库名>.git
cd <仓库名>
pip install -r requirements.txt
```

### 3. 配置题库

复制模板并填写：

```bash
cp config_template.ini config.ini
```

在 `config.ini` 的 `[tiku]` 段填入题库配置。**不配题库也能跑视频任务点**，
但需要答题的章节检测会被跳过。

### 4. 启动

**方式 A：单账号（最简单）**

```bash
python web_ui.py
```

浏览器会自动打开 `http://127.0.0.1:5000`。

**方式 B：多账号并行（推荐）**

```bash
python start_multi.py 3
```

一条命令启动 3 个账号实例 + 统一网关：

```
[启动] acc1：http://127.0.0.1:5000/
[启动] acc2：http://127.0.0.1:5001/
[启动] acc3：http://127.0.0.1:5002/
[启动] 网关：http://127.0.0.1:8888/
```

- 各实例数据分别落在 `chaoxing_data/acc1~acc3/`
- 打开 **网关** `http://127.0.0.1:8888/` 可一屏查看所有账号进度

## 多账号并行

### 原理

每个实例是**独立进程 + 独立端口 + 独立数据目录**：

```
chaoxing_data/
├── acc1/   cookies.txt · cache.json · learned_answers.json · ui_config.json
├── acc2/   ...
└── acc3/   ...
```

账号之间**读不到彼此的登录态、题库缓存与学习记录**。

### 可配置的环境变量

| 变量 | 默认 | 说明 |
|---|---|---|
| `CK_PORT` | `5000` | 实例监听端口 |
| `CK_HOST` | `127.0.0.1` | 监听地址 |
| `CK_DATA_DIR` | 项目根目录 | 数据目录（多实例隔离的关键） |
| `CK_GW_PORT` | `8888` | 网关端口 |
| `CK_STRICT` | `0` | 设 `1` 则实例也强制登录 |

> 不设置任何环境变量时，行为与上游完全一致（单实例、数据在项目根目录）。

### ⚠️ 并发建议

同一 IP 的请求密度过高会被平台判定异常并**回退进度**。推荐：

| 场景 | 做法 |
|---|---|
| 常用 | 同时开 **2 个**，每个「并发章节数」设 1 |
| 求稳 | 同时开 1 个轮流刷 |
| 挂机 | 开多个但**错峰启动**（用网关的「错峰启动」按钮） |

## 远程访问（可选）

想在手机上查看进度，用内网穿透把**网关端口**暴露出去即可：

1. 在 SakuraFrp（或任意 frp 服务）创建 **1 条 TCP 隧道**
2. 本地地址填 `127.0.0.1`，本地端口填 **`8888`**
3. **自动 HTTPS 必须开启**（关闭会导致服务端拒绝 HTTP 请求，返回 501）
4. 拿到形如 `https://xxx.xxx.com:12345/` 的公网地址即可

> **只占 1 条隧道**：网关会反向代理到所有账号实例，不需要每个账号一条隧道。

### 访问权限

| 身份 | 登录方式 | 权限 |
|---|---|---|
| 管理员 | 本机访问免登录，或输入**管理口令** | 全部功能 |
| 账号本人 | 输入**该账号的学习通账号密码** | 只看自己那个账号，可操作 |
| 只读访客 | 输入**只读口令** | 只能看进度，看不到任何账号信息 |

口令保存在数据目录的 `chaoxing_data/gateway_config.json`（网关口令）和
`chaoxing_data/acc{N}/ui_config.json`（实例会话密钥）中。首次运行若该文件不存在，
网关会**自动生成随机口令并打印到控制台和日志**。

**修改口令**：直接编辑 `chaoxing_data/gateway_config.json`，改完重启网关即可：

```json
{
  "admin_token":  "你的管理口令",
  "viewer_token": "你的只读口令",
  "secret_key":   "（自动生成，改了会让所有已登录用户下线）"
}
```

> **安全提示**：公网地址 + 管理口令等于完整控制权，请勿随意分享。
> 访客请只发**只读口令**。
> 只读口令建议不要设成 `000000` 这类可猜的弱口令 —— 虽然访客权限已在网关层
> 卡死（碰不到 `/acc/` 下的账号密码与 AI Key），但仍能看全部账号的进度。

## 实例控制台

登录网关后（`http://127.0.0.1:8888/`）就是账号总览，每个账号一张卡片。

| 控件 | 位置 | 作用 |
|---|---|---|
| **开关** | 每张卡片右下 | 切换该账号实例的启停。关掉后实例进程退出，卡片变灰 |
| **加号** | 页面右下角悬浮 | 新增一个账号，编号自动取「当前最大值 +1」 |
| **错峰启动** | 顶部工具条 | 按设定间隔依次启动所有已开启的实例 |
| **刷新** | 顶部工具条 | 手动刷新状态；平时每几秒自动刷新一次 |
| **停止所有服务** | 顶部工具条 | 一次性关掉全部实例 + 网关自己。会二次确认 |
| **打开该实例 →** | 卡片内 | 跳到 `/acc/{编号}/` 做该账号的登录选课与刷课 |

**编号不回收**：停掉 acc2 后再点加号，得到的是 acc4 而不是 acc2。
这是刻意的 —— 数据目录按 `acc{编号}` 命名，编号复用会让新账号看到旧账号的
登录态和题库缓存。

**加号上限**：默认最多 20 个实例（`gateway.py` 里的 `MAX_INSTANCES`）。

> **权限**：以上全部是管理动作，只读访客与普通账号用户都无法使用
> （网关层直接返回 403）。

### 用命令行批量起实例

界面之外，也可以用启动器一次起好（实例数按 `chaoxing_data/acc*` 目录自动推断）：

```bash
python start_multi.py          # 起全部已存在的账号实例 + 网关
python start_multi.py --one 4  # 只起 acc4（网关加号按钮内部用的就是这个）
```

python main.py                                  # 直接运行

## 目录结构

```
├── web_ui.py            # 单实例 Web 界面（Flask）
├── gateway.py           # 统一网关：认证 + 总览 + 反向代理 + 错峰调度
├── start_multi.py       # 多实例启动器
├── main.py              # 命令行入口
├── api/                 # 核心逻辑
│   ├── base.py          #   课程 / 章节 / 视频 / 答题
│   ├── answer.py        #   题库与 AI 答题
│   ├── learned.py       #   学习库（判对/判错的题目记忆）
│   ├── config.py        #   全局配置与数据目录
│   └── ...
├── resource/
│   └── font_map_table.json   # 题目字体解密表（必需）
├── models/              # ⚠️ 语音模型（需自行下载，见下）
└── chaoxing_data/       # 多实例数据（自动生成，已被 gitignore）
```

### 语音识别模型（可选）

听力题转文字需要 Whisper 模型，因体积（约 145MB）未纳入仓库。
需要时下载后放到 `models/fw-base/`，包含：

```
models/fw-base/
├── config.json
├── model.bin
├── preprocessor_config.json
├── tokenizer.json
└── vocabulary.txt
```

不需要听力题转文字功能的话**可以完全忽略**。

## 常见问题

**Q：界面日志区一片空白，只有零星几行？**
A：已修复（过滤了终端控制符）。若仍出现，请确认使用的是最新代码。

**Q：手机登录后刷新又被弹回登录页？**
A：已修复（会话密钥改为持久化）。旧版本每次重启会让人掉线。

**Q：隧道能连上但访问返回 501？**
A：隧道配置里「自动 HTTPS」被设成了禁用 —— 改成**开启**，并用 `https://` 访问。

**Q：多个账号同时刷会被判异常吗？**
A：会，取决于请求密度。请参考上方「并发建议」，或用网关的错峰启动。

**Q：想完全禁用本机免登录？**
A：设置环境变量 `CK_STRICT=1`。
